# SportLost

แอปพลิเคชันแจ้งและติดตามอุปกรณ์กีฬาที่สูญหายภายในมหาวิทยาลัยราชภัฏพิบูลสงคราม

## เกี่ยวกับโครงงาน

SportLost เป็นระบบสำหรับแจ้งและติดตามอุปกรณ์กีฬาที่สูญหายหรือพบภายในมหาวิทยาลัย ผู้ใช้สามารถแจ้งของหาย แจ้งของพบ ค้นหารายการ ติดต่อผู้เกี่ยวข้อง ยืนยันความเป็นเจ้าของ และติดตามสถานะการคืนอุปกรณ์ได้

## ฟีเจอร์หลัก

- สมัครสมาชิกและเข้าสู่ระบบ
- แจ้งอุปกรณ์สูญหาย
- แจ้งอุปกรณ์ที่พบ
- ค้นหารายการอุปกรณ์
- ดูรายละเอียดรายการ
- ส่งคำขอติดต่อ
- ยืนยันความเป็นเจ้าของ
- ติดตามสถานะการคืนอุปกรณ์
- Admin จัดการรายการประกาศและอัปเดตสถานะการคืนอุปกรณ์

- Backend: Node.js และ Express.js
- Database: PostgreSQL หรือ MySQL
- Version Control: Git และ GitHub
