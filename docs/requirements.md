# Requirements ของระบบ SportLost

## Functional Requirements

- ผู้ใช้สามารถสมัครสมาชิกและเข้าสู่ระบบได้
- ผู้ใช้สามารถแจ้งอุปกรณ์สูญหายได้
- ผู้ใช้สามารถแจ้งอุปกรณ์ที่พบได้
- ผู้ใช้สามารถค้นหารายการอุปกรณ์ได้
- ผู้ใช้สามารถส่งคำขอติดต่อได้
- ผู้ใช้สามารถยืนยันความเป็นเจ้าของได้
- Admin สามารถจัดการรายการและอัปเดตสถานะได้

## Non-Functional Requirements

- ระบบรองรับการใช้งานผ่านโทรศัพท์มือถือ
- ระบบตรวจสอบข้อมูลก่อนบันทึก
- ระบบรักษาความปลอดภัยของข้อมูลผู้ใช้
